# AutoPart — Full-Stack E-Commerce Platform

A full-stack automotive spare parts e-commerce platform built with an
iterative, AI-assisted development workflow.

## Tech Stack
- Next.js 14, Tailwind CSS
- Prisma ORM + MySQL
- NextAuth.js

## Features
- Product catalog (21 items) with cart & multi-step checkout
- Order history & admin dashboard
- Live chat with keyword auto-reply
- Animated UI components

## Getting Started
\`\`\`bash
git clone https://github.com/suryavania/autopart-ecommerce.git
cd autopart-ecommerce
npm install
cp .env.example .env   # then fill in your own DATABASE_URL
npx prisma migrate dev
npm run dev
\`\`\`
